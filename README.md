# Custom Emojis

Bu depo, Android için **Custom Emojis** adlı gerçek bir IME projesidir.

- Ana uygulamadaki **Değiştir** butonu Android klavye seçicisini açar.
- Custom Emojis sistem klavye listesinde görünür.
- Emoji düğmeleri seçildiğinde aktif uygulamaya emoji gönderilir.
- Özel görsel skinleri ileride `assets/emojis/` altında PNG olarak ekleyebilirsin.
- GitHub Actions debug APK üretir.

Not: Üçüncü taraf bir IME, Gboard'un Unicode emoji gliflerini diğer uygulamalarda sistem genelinde zorla değiştiremez. Özel görseller için uygulamanın resim içeriği/`commitContent` desteği gerekir.
